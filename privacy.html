Summary

Obsidian Vault Backup is a private tool run by one person, on that person's own computer, to back up that person's own files into that person's own Google Drive. It has no other users. It collects nothing from anyone else and sends nothing to anyone else.

What the tool accesses

The tool asks the owner's Google Account for the Google Drive scope (https://www.googleapis.com/auth/drive). This scope allows the tool to see, create, edit, and delete files in the owner's Google Drive. The tool only uses that access to read and write its own backup folders. It does not read, index, or modify any other files in the Drive.

Full Drive access is requested rather than a narrower scope because the backup tool (rclone) needs to manage the backup folders it created in earlier sessions. The owner can see and change this permission at any time.

What data is stored in Google Drive

  • Encrypted backup snapshots of the owner's Obsidian vaults, produced by restic.
  • All content is encrypted on the owner's computer before upload. The encryption password is held only by the owner, and is never sent to Google or to this website.
  • No Google Account data (name, email address, contacts, other files) is stored, copied, or shared by the tool.

Where data goes

  • From the owner's computer to the owner's Google Drive, over Google's own encrypted (HTTPS) API.
  • Nowhere else. There is no server operated by the owner, no analytics, no advertising, no data broker, and no third party that receives data from the tool.
  • The owner's computer may send a short status message (for example "backup succeeded" or "backup failed") to the owner's own private messaging channel. That message contains no file contents.

Retention

Backup snapshots are kept for 30 days, with at least the three most recent verified snapshots always retained, under a retention policy applied on the owner's computer. Older snapshots are removed from the backup repository on that schedule. Google's own data-retention and deletion behaviour for Drive files is described in Google's privacy policy.

Revoking access

The owner can revoke the tool's Google Drive access at any time at myaccount.google.com/permissions. Revoking access stops all further uploads. Files already in Google Drive stay there until the owner deletes them.

This website

This website is a static page hosted on GitHub Pages. It sets no cookies and runs no analytics or tracking scripts. GitHub, the host, may record ordinary web-server logs under GitHub's privacy statement.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. In practice, data obtained through Google APIs is used only to upload, verify, and prune the owner's own encrypted backups, and for nothing else.
